# Koozee for Kiro

Create fashion workflows on a free canvas. Batch-generate fashion images and videos.

This repository is the [Agent Plugins 1.0](https://agent-plugins.org) Power for Kiro IDE, CLI, and Web: `plugin.json`, `mcp.json`, and `skills/` at the repo root.

- Product: [koozee.ai](https://koozee.ai)
- MCP: `https://koozee.ai/business-api/mcp` (`streamable-http`)
- License: MIT

## Install

Clone this repository. The clone root is the plugin root.

```bash
git clone https://github.com/Koozee-Studio/koozee-kiro.git
```

In Kiro IDE: Powers → Add Custom Power → Import power from a folder → select this clone root.

The first MCP connection uses OAuth. Calls without login return 401.

Credits match the Koozee canvas. After the canvas changes, open the project URL Koozee returns.
